Resumo dos Endpoints
i
 Informações Gerais
Base URL
https://salve.icmbio.gov.br/salve-api/
Formato de Resposta
Todos os endpoints retornam 
application/json
 com a estrutura:
{
  "msg" : "",
  "status" : 200,
  "data" : [],
  "pagination" : {},
  "remoteIP" : "...",
  "url" : "...",
  "baseUrl" : "..."
}
Métodos HTTP
Todos os endpoints públicos utilizam apenas o método 
GET
.
Paginação
O endpoint 
search
 retorna paginação no campo 
pagination
 com os atributos: 
paginationPageSize
, 
paginationTotalRecords
, 
paginationPageNumber
, 
paginationTotalPages
, 
paginationFirstRowNum
.
Cache
As consultas são cacheadas em disco por 60 minutos (padrão). É possível alterar com o parâmetro opcional 
cacheMinutes
.
Controle de Acesso
Atualmente o acesso à API é 
público e irrestrito
. Os acessos são registrados para auditoria.
Criptografia de IDs
IDs de fichas e imagens são transmitidos criptografados (AES) nas URLs e válidos apenas no mesmo dia em que foram gerados. Utilize os valores retornados pela API nas requisições subsequentes.
Ficha HTML da Espécie
                    https://salve.icmbio.gov.br/#/?q={NOME DA ESPÉCIE}
                    https://salve.icmbio.gov.br/#/?q=puma concolor

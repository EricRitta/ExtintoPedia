i Informações Gerais

Base URL

https://salve.icmbio.gov.br/salve-api/

Formato de Resposta

Todos os endpoints retornam application/json com a estrutura:

{
  "msg" : "",
  "status" : 200,
  "data" : [],
  "pagination" : {},
  "remoteIP" : "...",
  "url" : "...",
  "baseUrl" : "..."
}

Métodos HTTP

Todos os endpoints públicos utilizam apenas o método GET.

Paginação

O endpoint search retorna paginação no campo pagination com os atributos: paginationPageSize, paginationTotalRecords, paginationPageNumber, paginationTotalPages, paginationFirstRowNum.

Cache

As consultas são cacheadas em disco por 60 minutos (padrão). É possível alterar com o parâmetro opcional cacheMinutes.

Controle de Acesso

Atualmente o acesso à API é público e irrestrito. Os acessos são registrados para auditoria.

Criptografia de IDs

IDs de fichas e imagens são transmitidos criptografados (AES) nas URLs e válidos apenas no mesmo dia em que foram gerados. Utilize os valores retornados pela API nas requisições subsequentes.

Ficha HTML da Espécie

https://salve.icmbio.gov.br/#/?q={NOME DA ESPÉCIE} https://salve.icmbio.gov.br/#/?q=puma concolor

1 Dashboard e Estatísticas

GET https://salve.icmbio.gov.br/salve-api/public/totalNumbers

Retorna os totais exibidos na página inicial: espécies avaliadas, espécies com ficha publicada, espécies ameaçadas e especialistas envolvidos.

Exemplo de resposta 
{
  "data": [
    { "order": 1, "label": "Espécies avaliadas", "value": 15123 },
    { "order": 2, "label": "Espécies com ficha publicada", "value": 10234 },
    { "order": 3, "label": "Espécies ameaçadas", "value": 3456 },
    { "order": 4, "label": "Especialistas envolvidos", "value": 890 }
  ],
  "howToCite": "..."
}
GET https://salve.icmbio.gov.br/salve-api/public/highlightedSpecies

Retorna uma lista aleatória de espécies em destaque para o carrossel de imagens da página inicial.

ParâmetroTipoObrig.Descrição

Exemplo de resposta 
{

      "cientificName": "Panthera onca",

      "category": "Vulnerável (VU)",
      "authorName": "Autor, N.",
      "downloadUrl": "https://salve.icmbio.gov.br/salve-api/public/speciePhoto/..."

  ]
}

2 Gráficos

GET https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedCategories

Dados para gráfico de espécies por categoria de avaliação (IUCN).

ParâmetroTipoObrig.Descrição
threatenedstringNãoFiltrar apenas ameaçadas (Y) ou não ameaçadas (N)
Exemplo

GET https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedCategoriesBiome

Dados para gráfico de categorias de avaliação filtradas por bioma.

ParâmetroTipoObrig.Descrição
biomestringNãoNome do bioma: Amazônia, Caatinga, Cerrado, Marinho, Mata Atlântica, Pampa, Pantanal
threatenedstringNãoApenas ameaçadas (S)
Exemplos 
https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedCategoriesBiome?biome=Cerrado
https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedCategoriesBiome?biome=Cerrado&threatened=S
https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedCategoriesBiome?threatened=S
GET https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedGroups

Dados para gráfico de espécies por grupo taxonômico.

ParâmetroTipoObrig.Descrição

https://salve.icmbio.gov.br/salve-api/public/graphEvaluatedGroups?threatened=Y&group=MAMIFEROS

7 Busca e Filtros

GET https://salve.icmbio.gov.br/salve-api/public/selectOptions

Retorna todos os valores para alimentar os campos de seleção da busca avançada (grupos, regiões, categorias, estados, biomas, etc.).

Utilize este endpoint para ter acesso aos IDs utilizados nas pesquisas abaixo.

GET https://salve.icmbio.gov.br/salve-api/public/search

Endpoint principal de busca. Retorna fichas de espécies com base nos filtros informados. Suporta paginação, ordenação e exportação dos resultados.

Parâmetros de busca textual

ParâmetroTipoObrig.Descrição
qstringNãoNome científico ou nome comum (mín. 3 caracteres; múltiplos separados por ;).
publicadastringNãoFiltrar por fichas publicadas: S ou N.
endemicaBrasilstringNãoEndêmica do Brasil: S ou N.
presencaListaVigentestringNãoPresente na lista oficial vigente: S ou N.
taxonIdlongNãoID do nível taxonômico.
autorNomestringNãoNome do autor.

Filtros geográficos e taxonômicos

ParâmetroTipoObrig.Descrição
categoriaIdsstringNãoIDs das categorias IUCN separados por vírgula.
grupoIdsstringNãoIDs dos grupos taxonômicos separados por vírgula.
regiaoIdsstringNãoIDs das regiões separados por vírgula.
estadoIdsstringNãoIDs dos estados separados por vírgula.
biomaIdsstringNãoIDs dos biomas separados por vírgula.
ucIdsstringNãoIDs das Unidades de Conservação separados por vírgula.
esferaUcstringNãoEsfera da UC: F (Federal), E (Estadual), R (Municipal).
baciaIdsstringNãoIDs das bacias hidrográficas separados por vírgula.
panIdsstringNãoIDs dos Planos de Ação Nacional separados por vírgula.
ameacaIdsstringNãoIDs das ameaças separados por vírgula.
usoIdsstringNãoIDs dos usos separados por vírgula.
threatenedstringNãoApenas ameaçadas: Y ou S.
pexstringNãoIncluir "Possivelmente Extinta": S.
selectedIdsstringNãoIDs criptografados de fichas pré-selecionadas (separados por vírgula).

Flags de endemicidade e presença

ParâmetroTipoDescrição
endemicaRegiaoS/NEndêmica da região.
endemicaEstadoS/NEndêmica do estado.
endemicaBiomaS/NEndêmica do bioma.
endemicaBaciaS/NEndêmica da bacia.
presencaAtualRegiaoS/NPresença atual na região.
presencaAtualEstadoS/NPresença atual no estado.
presencaAtualBiomaS/NPresença atual no bioma.
presencaAtualBaciaS/NPresença atual na bacia.

Paginação e ordenação

ParâmetroTipoDescrição
paginationPageSizeintQuantidade de registros por página.
paginationPageNumberintNúmero da página (retornado na resposta anterior).
paginationTotalPagesintTotal de páginas (retornado na resposta anterior).
paginationTotalRecordsintTotal de registros (retornado na resposta anterior).
sortColumnstringNome da coluna para ordenação.
sortOrderstringasc ou desc.

Exportação

ParâmetroTipoDescrição
exportstring Formato de exportação: row (planilha), pdf (PDF), reg (registros de ocorrência). Padrão: HTML (JSON paginado).
emailstringE-mail para notificação quando a exportação assíncrona estiver concluída.
reCaptchaTokenstringToken do reCAPTCHA v3 (atualmente não exigido).
Exportação assíncrona: Ao usar export=row, export=pdf ou export=reg, a resposta retorna um pid (ex.: job-xxxxx). Consulte o progresso em https://salve.icmbio.gov.br/salve-api/public/job/{pid}. Quando finalizado, um link de download é disponibilizado.
Exemplos de uso 
https://salve.icmbio.gov.br/salve-api/public/search?q=Puma concolor
https://salve.icmbio.gov.br/salve-api/public/search?categoriaIds=134&paginationPageSize=100
https://salve.icmbio.gov.br/salve-api/public/search?q=onça&export=pdf
https://salve.icmbio.gov.br/salve-api/public/search?biomaIds=22&presencaAtualBioma=S

8 Utilitários

GET https://salve.icmbio.gov.br/salve-api/public/job/{pid}

Consulta o andamento de um job de exportação assíncrona. O pid é retornado pelos endpoints de exportação (search?export=...).

ParâmetroTipoObrig.Descrição
pidstringSimPID do job (ex.: job-xxxxx).
Exemplo de resposta 
{
  "data": {
    "pid": "job-12345-01-01-2025-12-00-00",
    "percent": 100,
    "running": false,
    "fileName": "salve-exportacao-ficha-...csv",
    "downloadUrl": "https://salve.icmbio.gov.br/salve-api/public/download?fileName=..."
  }
}
GET https://salve.icmbio.gov.br/salve-api/public/download

Faz o download de um arquivo gerado por exportação assíncrona. Utilizado internamente pelo endpoint /job.

ParâmetroTipoObrig.Descrição
fileNamestringSimNome do arquivo para download.
